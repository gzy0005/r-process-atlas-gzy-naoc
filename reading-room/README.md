# R-process Atlas · 光谱阅读室

此目录是主站的文献与方法阅读分支；主站 `/` 继续提供恒星检索、丰度图表和数据下载。

来源聊天：确认不同巡天结果尺度是否统一（01a1abd3-2442-7be3-a790-09582a533bcb）。迁移其公开阅读室的2026-11-07构建产物：41页连续中英对照阅读、原页查看、10幅图表、288篇参考文献与交互脉络图。方法说明中保留“已核实引用”和“段落共现”的区别。

- `index.html`：完整阅读，支持章节、搜索、字号、原页与位置恢复。
- `references.html`：默认显示有连线的核心脉络，支持全部文献、筛选、标题与关系证据。
- `assets/`：迁移所用图表、公式、英文原页及PDF，页面不依赖旧阅读室的图像服务。

原论文 Melissa K. Ness, Data-Driven Methods in Spectroscopy (2026)，DOI https://doi.org/10.1146/annurev-astro-052722-095654 。依据所提供的41页提前在线版本；非期刊官方译文。

此接入只增设阅读入口，不执行任何巡天丰度校准，不改变主站星表记录或原始测量。代码分支：`codex/spectroscopy-reading-room`。
